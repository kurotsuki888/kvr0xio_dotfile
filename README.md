# ⚡ kvr0xio_dotfile

Mis configuraciones personalizadas para **Hyprland**, **Waybar**, **Quickshell**, **Kitty**, **Rofi**, **Zsh** y **Powerlevel10k**.

## 🎨 Componentes Incluidos

- **Hyprland** (`~/.config/hypr`) - Configuración de ventanas, animación wind, atajos y reglas.
- **Waybar** (`~/.config/waybar`) - Barra superior con módulos y scripts interactivos.
- **Quickshell** (`~/.config/quickshell`) - Popups radiales e interactivos de Wi-Fi, Bluetooth, Notificaciones, Calendario, Hora y Sistema.
- **Kitty** (`~/.config/kitty`) - Configuración del terminal.
- **Rofi** (`~/.config/rofi`) - Lanzador y menús gráficos.
- **Zsh & Powerlevel10k** (`~/.zshrc`, `~/.p10k.zsh`) - Prompt y terminal estilizado.

## 🚀 Instalación rápida en una nueva PC

```bash
git clone https://github.com/TU_USUARIO/kvr0xio_dotfile.git ~/kvr0xio_dotfile
cd ~/kvr0xio_dotfile
./install.sh
```
